# Repause 프리미엄 리디자인 기록

## 목적
- 일반 숙소 사이트가 아니라 `프리미엄 펜션 예약 사이트`에 맞는 톤으로 재정렬
- 감성 소개 위주 구조에서 `예약 판단이 빠른 구조`로 전환
- 관리자/예약 도메인과 공용 사이트 톤을 더 일관되게 연결

## 레퍼런스 비교 요약
- `브릭나인`: 낮은 곡률, 강한 여백, 건축 사진 중심, 직선적인 화면 문법
- `스테이폴리오`: 정보 우선순위가 명확하고 검색/예약 판단이 빠름
- `기존 Repause`: 베이지 카드 반복, 둥근 모서리 과다, 감성 랜딩 템플릿 인상

## 기존 문제
1. 카드형 섹션이 반복되어 화면 기억점이 약했음
2. 곡률이 커서 프리미엄 독채보다 웰니스/라이프스타일 앱처럼 보였음
3. 예약 판단 정보가 뒤로 밀려 전환 흐름이 약했음
4. 헤더/푸터/서브페이지가 너무 안전해서 브랜드 개성이 약했음
5. 예약 폼과 캘린더가 실제 예약 도구보다 정보 박스처럼 보였음

## 적용 방향
- 곡률 축소: pill 버튼과 large radius를 줄이고 선형 레이아웃 강화
- 대비 강화: 밝은 바탕과 진한 잉크 톤의 대비를 키움
- 카드 축소: 독립 카드 대신 `border`, `grid`, `editorial section` 위주로 재구성
- 정보 선배치: 운영 상태, 인원, 체크인 정보 등을 히어로 직후 또는 예약 페이지 상단에 배치
- 프리미엄 문법: 이미지, 문장, 여백, 분할선 중심의 구성으로 전환

## 디자인 컨텍스트

### 사용자와 목적
- 주요 사용자는 `조용한 커플 여행`, `깊이 있는 기념일`, `소규모 회복형 휴식`을 찾는 고객
- 이 사이트의 핵심 목적은 숙소를 화려하게 소개하는 것이 아니라 `이곳에서 쉬고 싶다`는 감정과 `여기면 예약해도 되겠다`는 판단을 동시에 만드는 것
- 사용자는 빠르게 가격, 인원, 운영 상태를 확인하면서도 브랜드가 주는 정서적 설득을 함께 기대함

### 브랜드 성격
- 핵심 성격은 `고요함`, `절제됨`, `감각적 정돈`
- 리포즈는 럭셔리를 과시하는 브랜드가 아니라 `쉼의 밀도`를 높여 주는 프라이빗 스테이 브랜드
- 감정선은 따뜻하지만 들뜨지 않아야 하며, 자신감은 있어도 과장되면 안 됨

### 톤 앤 매너
- 문장은 짧고 차분하게 유지
- 판매형 과장 문구보다 `머무는 장면`, `쉼의 상태`, `공간의 리듬`을 묘사하는 방식 우선
- "최고", "압도적", "완벽한" 같은 과장형 표현은 지양
- 사용자를 재촉하는 카피보다 `조용히 권유하는 문장`을 사용
- 예약/정책/안내 문구는 감성보다 `신뢰`, `명확성`, `운영 안정감`을 우선

### 프론트 비주얼 방향
- `에디토리얼한 프리미엄 스테이 사이트` 문법을 유지
- 베이지, 아이보리, 브라운, 짙은 잉크 톤 중심의 절제된 팔레트 사용
- 둥근 카드 반복보다 `직선`, `분할선`, `큰 사진`, `정돈된 그리드` 중심으로 구성
- 영문 타이틀은 브랜드 무드, 한글 본문은 가독성과 밀도를 담당하는 구조 유지
- 현재 기준 타이포 방향은 `Bodoni Moda + Song Myung + Manrope`

### 피해야 할 방향
- 웰니스 앱, 감성 라이프스타일 쇼핑몰, 리조트 프로모션처럼 보이는 화면
- 보라 계열 위주 팔레트, 과한 글로우, 유리질 효과, 장식성 애니메이션 남발
- 작은 카드 다발, 배지 남발, 정보보다 스타일이 앞서는 템플릿형 구성
- 지나치게 밝고 귀여운 카피, 또는 반대로 호텔 안내문처럼 딱딱한 운영 문구

### 디자인 원칙
1. 첫 화면은 브랜드 무드와 예약 판단 정보를 함께 보여준다.
2. 모든 섹션은 `고요함`과 `신뢰감`을 해치지 않는 선에서만 장식한다.
3. 감성 카피는 분위기를 만들고, 예약/정책 카피는 불안을 줄이는 역할로 분리한다.
4. 사진, 여백, 타이포 자체가 브랜드 경험이 되도록 하고 UI 장식은 최소화한다.
5. 단일 숙소 사이트인 만큼 사용자의 시선을 다른 상품보다 `리포즈 예약 결정`에 집중시킨다.

## 이번에 반영한 항목
- 홈을 카드 랜딩에서 편집형 프리미엄 구조로 재구성
- 공간 소개를 장면 순서 중심 레이아웃으로 변경
- 이용 안내를 카드 목록에서 선형 정보 구조로 변경
- 예약 / 제휴 페이지의 캘린더, 폼, 요약 정보 스타일 전면 수정
- 헤더/푸터/PageHero의 공통 톤을 더 절제된 방향으로 수정
- 약관/개인정보 페이지도 같은 톤으로 정렬

## 2차 보강
- 공개 헤더에서 `ADMIN` 링크를 제거해 브랜드 노이즈를 줄임
- `Bodoni Moda + Song Myung + Manrope` 조합으로 영문/한글/본문 타이포 위계를 재정의
- 홈과 서브 페이지의 전략 문구형 라벨을 사용자 중심 카피로 교체
- 예약 페이지 상단에 운영 상태, 예약 노트, 신뢰 정보 스트립을 추가
- 예약 폼의 인원/도착 시간 입력을 선택형으로 바꿔 실제 예약 도구처럼 정리
- 공간 소개의 이미지 라벨과 실제 장면 순서를 맞춰 디테일 오류를 제거

## 생성 자산 판단
- 이번 단계는 구조, 카피, 폰트, 예약 판단 흐름을 먼저 바로잡는 것이 우선순위였음
- Gemini 기반 이미지/영상 생성 스크립트는 준비되어 있지만, 현재 자산만으로도 톤 정리가 가능해 우선 보류
- 추후 실제 촬영 컷이 부족한 구간에 한해 보조 비주얼 생성 여부를 다시 판단
