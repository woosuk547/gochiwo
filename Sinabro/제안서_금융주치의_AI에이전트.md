# 아이디어 제안서: 금융 주치의 AI 에이전트

**과제**: 과학기술정보통신부 - AI 에이전트로 일상 바꾸기
**제출 마감**: 2026년 4월 15일 18:00

---

## 1. 아이디어 제목

**"금융 주치의" - 금융 취약계층을 위한 자율형 AI 금융 케어 에이전트**

---

## 2. 한 줄 요약

신용등급이 낮거나 금융 정보가 부족한 1,000만 국민을 위해, AI 에이전트가 개인 재정 상황을 스스로 진단하고 합법적인 서민 금융 상품을 자율적으로 탐색·매칭·신청까지 대행해주는 서비스

---

## 3. 문제 정의 (현재 일상의 불편)

### 현황
- 국내 금융 취약계층: 저신용자(7~10등급) 약 300만명, 금융 문맹 고령층 800만명+, 다문화 가족 140만명
- 잠재 수혜 대상: **약 1,000만명 이상**

### 핵심 문제
| 문제 | 내용 |
|------|------|
| 정보 비대칭 | 햇살론, 새희망홀씨, 버팀목 등 정부 서민 금융 상품이 수십 개지만 본인에게 맞는 것을 찾기 어려움 |
| 불법 사금융 피해 | 연간 피해 규모 3조원 이상, 저신용자가 주요 타겟 |
| 신청 장벽 | 복잡한 서류와 절차로 실제 신청까지 포기하는 비율 높음 |
| 기존 AI 한계 | 토핑플러스(뱅크샐러드), 마샤오차이 등 기존 금융 AI는 모두 신용등급 높은 사람 대상 |

### 왜 AI 에이전트인가?
기존 생성형 AI는 "햇살론 알려줘" → 정보 제공에서 끝남.
**AI 에이전트는 스스로 탐색하고, 계획하고, 신청까지 실행함.**

---

## 4. 아이디어 상세 (AI 에이전트 자율 실행 흐름)

### 서비스명: 금융 주치의 (Financial Care Agent)

### Step-by-Step 자율 실행 구조

```
[사용자 입력]
"저 신용등급 6등급인데 전세자금 500만원이 급하게 필요해요"

       ↓ 에이전트 자율 실행 시작

[Step 1] 재정 상황 자율 진단
  - 소득, 지출, 현재 부채, 신용등급 수집
  - 필요 금액, 상환 가능 금액 자동 계산
  - 긴급도 및 목적 분류

       ↓

[Step 2] 공공 금융 데이터베이스 자율 탐색
  - 서민금융진흥원 API 연동
  - 금융감독원 공시 데이터 실시간 조회
  - 지역 신협/새마을금고 조건 탐색
  - 적합 상품 5개 자동 선별

       ↓

[Step 3] 불법 사금융 자동 경고 + 합법 상품 매칭
  - 입력한 업체명/연락처를 불법 사금융 DB와 자동 대조
  - 위험 감지 시 즉시 경고 + 대안 안내
  - 적합 상품 조건 상세 비교표 자동 생성

       ↓

[Step 4] 신청 서류 자동 작성 지원
  - 필요 서류 목록 자동 안내
  - 공통 항목 자동 입력 (이름, 주소 등)
  - 제출처/방문 예약 자동 연결

       ↓

[Step 5] 신용 개선 로드맵 수립 + 주기적 모니터링
  - 3개월/6개월 신용 개선 계획 자동 수립
  - 매월 재정 변화 모니터링
  - 새로운 적합 상품 등장 시 자동 알림
```

### 에이전트 핵심 특징
- **자율성**: 사용자가 한 문장 입력 → 에이전트가 5단계 자율 실행
- **멀티모달**: 텍스트 + 문서 사진(급여명세서 등) 자동 인식
- **지속 실행**: 1회 상담이 아닌 지속적 금융 케어 관계 형성

## 5. 기대 효과 (파급력)

### 직접 효과
| 지표 | 내용 |
|------|------|
| 수혜 대상 | 금융 취약계층 약 1,000만명 |
| 불법 사금융 피해 예방 | 연간 3조원 피해 중 일부 차단 |
| 정부 서민 금융 이용률 향상 | 햇살론 등 정책 금융 실효성 증대 |

### 사회적 효과
- **금융 포용성 확대**: 소외 계층의 제도권 금융 접근성 향상
- **디지털 금융 격차 해소**: AI가 복잡한 금융 절차를 대신 처리
- **정책 효과 증대**: 정부가 만든 서민 금융 상품의 실제 활용률 향상

### 후속 연계 가능성
- 행안부 민원 시스템 연동 (공공 서비스 통합)
- 서민금융진흥원 공식 채널화
- 지자체 복지 서비스와 연동 확장

## 6. 실현 가능성

### 기술 스택 (웹개발자 관점에서 즉시 구현 가능)
```
프론트엔드:  Next.js 14 (App Router)
AI 에이전트: Claude API (claude-opus-4-6) + Tool Use
공공 데이터: 서민금융진흥원 API, 금융감독원 공시 API (무료 개방)
데이터베이스: PostgreSQL (금융 상품 DB)
배포:        Vercel / Railway
```

### 구현 가능 이유
1. **공공 API 존재**: 서민금융진흥원·금감원이 이미 API 개방
2. **Claude Tool Use**: 자율 실행 에이전트 구현에 최적
3. **3일 내 데모 가능**: 핵심 기능(진단→탐색→매칭) Next.js로 즉시 구현

### 규제 준수 방안
- 실제 금융 계약 체결은 에이전트가 아닌 사용자가 최종 결정
- 개인정보는 세션 내에서만 처리, 서버 저장 없음
- 금융업 라이선스 불필요 (정보 제공 및 신청 보조 서비스)
